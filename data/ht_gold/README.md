# Haitian Creole Gold Corpus (ht_gold)

This directory contains **human-verified, high-quality Haitian Creole transcripts**
used as *gold reference data* for evaluating and improving KreyAI.

## Purpose
- Measure transcription quality (WER, CER, normalization accuracy)
- Evaluate HT density detection
- Validate A3 normalization behavior
- Track longitudinal improvement of the Creole pipeline

## Rules
- Texts must be **manually corrected by a fluent speaker**
- No automatic normalization allowed in gold files
- Keep original meaning, register, and style
- Use `[Unintelligible]` where audio is unclear
